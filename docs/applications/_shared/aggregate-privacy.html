AGG — Aggregate Privacy 1.0 Ontology agg:

Namespace https://markjspivey-xwisee.github.io/interego/applications/_shared/aggregate-privacy# · version 1.0 · 11 terms.

Shared vocabulary for privacy-preserving cohort aggregation across pods: opt-in participation, Merkle-attested counts, homomorphic Pedersen sum and distribution bundles, differential-privacy budget audit logs, and threshold-committee authorization and reconstruction records. Payload terms are carried inside Interego (iep:) typed context descriptors — the descriptor layer supplies identity, provenance, temporal validity and access control; agg: supplies the aggregation domain.

Machine-readable form: aggregate-privacy.ttl (Turtle) — the authoritative source. This page is a human-readable projection of it; each term below is identified by a hash IRI under this base (e.g. agg:cohort = https://markjspivey-xwisee.github.io/interego/applications/_shared/aggregate-privacy#cohort).

Terms

agg:AttestedHomomorphicDistributionBundle Class
A published zk-distribution result: per-bucket homomorphic Pedersen sums and per-bucket DP-noised counts over a one-hot bucketing scheme, structurally verifiable bucket by bucket.
agg:AttestedHomomorphicSumBundle Class
A published zk-aggregate result: a homomorphic Pedersen sum over per-contributor commitments plus DP-Laplace noise calibrated to a declared epsilon. Re-verifiable by any auditor against the contributor commitments.
agg:CohortParticipation Class
A participant's self-asserted, revocable opt-in to a cohort aggregation. Published on the participant's own pod so the aggregator must discover consent rather than assume it; revoked by re-publishing a Counterfactual descriptor at the same IRI.
agg:CommitteeAuthorization Class
An operator's signed pre-commitment to the n authorized committee DIDs and the (n, t) threshold, published BEFORE shares are distributed. Cross-checked at audit time against the actual reveal committee, which is what catches an operator improvising a sock-puppet committee.
agg:CommitteeReconstructionAttestation Class
The chain-of-custody record of a threshold reveal: each participating committee member's signature over the bundle commitment, the claimed true sum, the member set and the reveal time, so a regulator can see who actually reconstructed and on which bundle.
agg:EncryptedShareDistribution Class
A verifiable Shamir share wrapped in an X25519/nacl envelope keyed to one intended pseudo-aggregator, published as an ordinary descriptor so the recipient collects it through standard pod discovery instead of an out-of-band channel.
agg:SignedBudgetAuditLog Class
An operator-signed snapshot of an epsilon budget: the per-query consumption log plus the cumulative spend, signed so the accounting itself is tamper-evident rather than merely honest.
agg:bundleJson Datatype property
The verifiable bundle serialized as a single JSON literal. Deliberately opaque to the triple store: the verifier re-hashes these exact bytes, so decomposing them into triples would let a round-trip through any normalizing store silently break every signature over the bundle.
agg:cohort Object property
The cohort this participation opts into.
agg:participant Object property
The DID of the agent or person opting in. Also the asserting agent and issuer of the descriptor — participation is self-asserted by construction.
agg:policy Object property
The cohort-aggregation policy descriptor the participant is consenting to. Optional: absent means the participant opted in without binding themselves to a published policy.
