Five roles and the capabilities each permits. Roles are DATA: a workspace wanting different governance publishes a different profile rather than requiring a new release.

Machine-readable form: wsp-roles-default.ttl (Turtle) — the authoritative source. This page is a human-readable projection of it.

What this is for

wspr:Convener / Steward / Contributor / Observer / Delegate Roles
A role is a CEILING, never a grant. Effective capability is role.permits ∩ delegatedScope, so holding a role cannot give a principal something their own delegation does not already carry, and an unresolvable delegation yields nothing rather than everything.
