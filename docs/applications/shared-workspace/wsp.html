Shared Workspace (WSP) 1.0 wsp:

Namespace https://markjspivey-xwisee.github.io/interego/applications/shared-workspace/wsp#

A workspace where several people and several agents work together, without any of them giving up custody of what they wrote. A workspace IS one dereferenceable graph URL whose content is the roster and the governance; the work is the union of one append-only log per participant, each on that participant’s own pod.

Machine-readable form: wsp.ttl (Turtle) — the authoritative source. This page is a human-readable projection of it.

What this is for

wsp:Workspace Class
Names exactly one convener and one role profile. Both are checked against this record rather than taken from a caller — see the residual-gap ledger in the application README for what that does and does not establish.
wsp:MembershipGrant / wsp:MembershipAcceptance Classes
The two halves of a membership. A grant lives on the convener’s pod, an acceptance on the member’s own; a roster entry exists only where both agree, because the substrate cannot make a person’s pod hold a record they did not write.
wsp:Entry / wsp:Reference Classes
One append to a participant’s own log, and a citation of another vertical’s record by its own IRI — never a copy, so the cited record keeps its authorship, shape and access control.
