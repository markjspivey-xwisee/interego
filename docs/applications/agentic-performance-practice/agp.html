Namespace https://markjspivey-xwisee.github.io/interego/applications/agentic-performance-practice/agp# · 210 terms and method resources.

Vertical-scoped, non-normative vocabulary for a complexity-aware, regime-first theory of performance for agents and teams of agents + humans. NOT part of the Interego protocol. Composes iep:, abac:, passport:, olke:, amta:, adp:, ac:, and Foxxi's xAPI 2.0 / IEEE-LER / ADL-TLA standards layer.

Machine-readable form: agp.ttl (Turtle) — the authoritative source. This page is a human-readable projection of it; each term below is identified by a hash IRI under this base (e.g. agp:Actualization = https://markjspivey-xwisee.github.io/interego/applications/agentic-performance-practice/agp#Actualization).

Consulting and intervention methods

The ontology includes a performance consulting and management cycle plus methods for instruction, in-flow support, reference, practice, assessment, coaching, probes, environmental changes and monitoring without intervention. Each profile defines steps, required work products, evidence criteria and revision paths. These are project-authored practice profiles; evidence coverage does not certify quality or prove effects.

Read and follow the live method catalogue. The full connected graph is included in the Turtle representation above.

agp:claimedOperator claimed operator
An operator identity the CALLER supplied and this bridge did not verify. A string, deliberately - not an IRI and not an agent identity - because publishing it as either would state as fact something nobody proved. This bridge authenticates no caller, so an `operator_did` in a request body is a claim about who is asking, and the descriptor says exactly that. The provenance, the asserting agent and the trust issuer all name the BRIDGE, which is what actually asserted the artifact; `iep:SelfAsserted` is then true of the thing it describes rather than a borrowed identity. Before this existed the caller's string went straight into prov:wasAttributedTo and into the Trust facet's issuer, so an anonymous request could publish a descriptor reading 'X self-asserted this' about an X that had done nothing - the same shape as the caller-supplied issuer_did that chose a signing key in #168.

agp:PerformanceAffordance Performance Affordance (ecological)
An action-possibility a situation OFFERS a performer, conditional on the performer's capability. This is affordance theory in the ECOLOGICAL sense (what the situation affords given capability), NOT the L0 iep:Affordance (a followable REST/HATEOAS hypermedia transition). The two are different layers and MUST NOT be conflated: a performance affordance is a possibility for performance; a iep:Affordance is a machine-followable action on a resource. A performance affordance MAY ultimately be realized THROUGH iep:Affordances, but is not one.

agp:verdict verdict
What an intervention evaluation concluded: 'closed' (the gap is gone), 'improved', 'no-change', 'worsened', or 'too-early' (the outcome is not yet observable). The engine has always decided this and it was returned to the caller and never written, so every agp:InterventionEvaluation on a pod recorded WHICH intervention it judged and nothing about the judgement. A verdict other than 'too-early' also carries iep:success — the protocol-level boolean projection of the same decision — while 'too-early' carries none, because an outcome nobody has asserted must not become one a serializer invented.

The unclassified state (no derived regime) corresponds to adp:Confused and routes to classify-first.
