Linked read-procedure profile

An optional L3 client example profile for Interego. The executable definition uses PROV plans, directed RDF edges, Hydra operations, and bound descriptor authority. Domain-specific performance, SCORM, and xAPI logic stays in the example.

Turtle vocabulary and structural shapes · Interpreter, example, and measured results

Classes

pr:Procedure
A finite read-only plan expressed as directed RDF steps. This optional L3 client profile does not add a core MCP tool. Grounded in prov:Plan.
pr:Step
One part of a procedure plan. Network steps additionally declare Hydra GET operations; local steps evaluate only the installed expression vocabulary. Grounded in prov:Plan.
pr:RunRequest
A signed invocation description linking an immutable procedure publication, its current-head pin, and explicit input data. Grounded in prov:Entity.
pr:Binding
A data binding from a named procedure input, preceding step result, or collection item, using a relative JSON Pointer. Grounded in prov:Entity.
pr:Expression
A data description evaluated by the installed client interpreter. It never contains executable code. Grounded in prov:Entity.
pr:Object
An object expression with unique named field resources; its internal JSON projection is not the publication format. Grounded in pr:Expression.
pr:Equal
Structural equality of left and right expressions. Grounded in pr:Expression.
pr:Nonempty
True only for a nonempty string or array. Grounded in pr:Expression.
pr:And
Conjunction of one or more condition resources, independent of RDF triple order. Grounded in pr:Expression.
pr:All
A condition applied to every member of a nonempty collection. An empty collection fails. Grounded in pr:Expression.
pr:ObservedRepresentation
The authenticated host's observed response to a declared read operation; observation alone is not proof of every embedded claim. Grounded in prov:Entity.
pr:EvidenceReviewExecution
An execution that reviews linked performance and learning evidence. Completion does not imply a new assessment or acquired competence. Grounded in prov:Activity.

Step kinds

pr:Read
Invoke an installed generic read capability with bound arguments.
pr:Check
Continue only when all declared preconditions hold; otherwise return Blocked.
pr:Select
Select exactly one executable, input-free GET control from observed data.
pr:Pick
Select exactly one data item or typed link from observed data.
pr:Project
Interpret an observed representation with a preinstalled media interpreter.
pr:Follow
Follow the selected descriptor-bound GET control using the existing generic act capability.
pr:Expect
Compare a caller expectation with observation and return NeedsDecision on mismatch.
pr:Output
Return a bound output value and terminate the procedure.

Profile boundary

Finite acyclic read-only plans, at most 64 steps, terminal output, bounded calls, pure expressions, and uniquely discovered input-free GET controls. This profile supplies no new server-side execution action. Full binding and condition resources remain in the signed RDF authority.

Blocked
A required integrity or consistency check failed.
NeedsDecision
Return to the caller. Any continuation begins a fresh invocation.
